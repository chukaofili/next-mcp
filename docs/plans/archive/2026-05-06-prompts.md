### When to use this prompt
- When you have a Docker daemon running, ~30–60 minutes of focus,
  and network access to npm + GitHub + better-auth-ui.com.

### Notes for adapting the prompt
- For a single-variant smoke (e.g., just the everything-on full
  smoke), drop the variant list and tell the assistant directly
  which one you're running.
- If you want the assistant to be more autonomous (e.g., update the
  Findings section without confirmation), relax rule 4. Default is
  conservative because the doc is the source of truth for the
  merge decision.
- If a finding turns into "this is actually a bug", switch sessions
  to one with Prompt 1 active (or a fresh implementer-style
  session) — the smoke session is read-only by design.

1. Any new findings get filed as issues; the recommended-fixes

   canonical record. Move smoke-discovered bugs from Tier 1 into a
   "Smoke findings" subsection or link to filed issues.

   merge. Tier 5b (yarn) and Tier 5a `--full` are deferred — don't
   block on them.

   from smoke-v2's §9 "Findings" section as part of the PR
